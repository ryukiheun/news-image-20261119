"Six Stories, One Thursday" — a 1024×1024 infographic summing up Thursday 19 November 2026 in six stories: GTA VI goes live worldwide after a 13-year wait; Trump, Xi and Putin hold the first-ever three-way summit in Shenzhen; the ICJ rules today in the Rohingya genocide case against Myanmar; new US AI chip export curbs take effect; Bumrah strikes on day one of the India–New Zealand Test in Wellington; and the Las Vegas Grand Prix weekend opens on the Strip. Drawn with Pillow in `draw_image.py`. Running `draw_image.py` regenerates `entry.png`; `main.py` only copies the finished `entry.png` to the output directory. Sources: AFP, Reuters, AP, NDTV, US BIS, RACER.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
